# Saucedemo QA Testing (E-Commerce)⁠
การทดสอบ Test Plan เเละกรณีทดสอบ Test Case สำหรับระบบซื้อขายสินค้าบนเว็บไซต์ 
# QA Portfolio - Manual Testing (Swag Labs / SauceDemo)

ยินดีต้อนรับสู่ Repository นำเสนอผลงานและทักษะด้าน Manual Testing โดยโปรเจกต์นี้เป็นการทดสอบเว็บแอปพลิเคชัน E-Commerce เพื่อนำเสนอแนวคิด การออกแบบเอกสาร และกระบวนการทดสอบซอฟต์แวร์อย่างเป็นระบบสำหรับเตรียมความพร้อมในการทำงานจริง

## Project Overview (ภาพรวมโปรเจกต์)
โปรเจกต์นี้เป็นการทดสอบระบบซื้อขายสินค้าออนไลน์บนเว็บไซต์ **Swag Labs (SauceDemo)** ครอบคลุมตั้งแต่กระบวนการเข้าสู่ระบบ การเลือกสินค้า ตะกร้าสินค้า ไปจนถึงขั้นตอนการสั่งซื้อ (Core Purchasing Flow) เพื่อให้มั่นใจว่าฟังก์ชันการทำงานหลักของระบบเป็นไปอย่างถูกต้องและมีประสิทธิภาพ
**เว็บไซต์ระบบทดสอบ:** SauceDemo (Swag Labs) https://www.saucedemo.com/

## Skills & Tools (ทักษะและเครื่องมือที่ใช้)
### Testing Skills
* **Test Planning:** การวางแผน กำหนดขอบเขต (Scope), กลยุทธ์ (Strategy) และตารางเวลาการทดสอบ
* **Test Case Design:** การออกแบบเคสการทดสอบที่ครอบคลุมทั้ง Positive & Negative Testing
* **Functional & UI Testing:** การทดสอบความถูกต้องของฟังก์ชันและการแสดงผลบนหน้าเว็บ
* **Test Documentation:** การจัดทำเอกสาร Test Plan และ Test Case ตามมาตรฐาน QA

### Tools Used
* **Google Docs:** จัดทำเอกสาร Test Plan  และบันทึกผลการทดสอบ (Actual Result / Status)
* **GitHub:** จัดเก็บไฟล์ นำเสนอผลงาน และจัดทำ README สำหรับ Portfolio

## Scope of Testing (ขอบเขตการทดสอบ)
* ## In-Scope (สิ่งที่เราทดสอบ)
* ระบบการเข้าสู่ระบบ (User Authentication & Login Validation)
* การเลือก ดูรายละเอียด และจัดเรียงรายการสินค้า (Product Listing & Sorting)
* การเพิ่ม/ลบ สินค้าในตะกร้า (Shopping Cart Management)
* ขั้นตอนการสั่งซื้อและกรอกข้อมูลจัดส่ง (Checkout Process)
* ## Out-of-Scope (สิ่งที่ไม่ทดสอบ)
* ระบบสมัครสมาชิกใหม่ (Sign up)
* การตัดเงินผ่าน Payment Gateway จริง
* Performance Testing & Security Testing
